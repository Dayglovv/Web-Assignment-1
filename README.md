# HTML & CSS Assignment 1

## Description

This project contains my HTML and CSS assignment.

The project includes 5 tasks. Each task demonstrates different HTML and CSS features.

## Tasks

### Task 1 — Personal Webpage

A personal webpage with my information, photo, lists, links and profile card.

### Task 2 — Simple Webpage Layout

A webpage with a header, navigation bar, sidebar, main content and footer. The layout is created using divs and CSS positioning.

### Task 3 — Tribute Page

A tribute page about a famous person. It contains information, an image, important events, contributions and links.

### Task 4 — Table and Form

A webpage with a styled student grades table and a feedback form.
